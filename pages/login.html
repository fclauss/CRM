Accès restreint
Vous devez être connecté avec un compte Google autorisé pour accéder à cette application.
Comment se connecter?
Cette application utilise votre compte Google pour l'authentification. Seuls les comptes autorisés peuvent y accéder.
  • Cliquez sur le bouton ci-dessous
  • Connectez-vous avec votre compte Google
  • Autorisez l'application si demandé
Problèmes de connexion?
Si vous pensez que vous devriez avoir accès mais que vous rencontrez des difficultés:
  • Vérifiez que vous utilisez le bon compte Google
  • Assurez-vous que les cookies sont activés
  • Essayez de vous déconnecter puis reconnecter
  • Contactez l'administrateur si le problème persiste
